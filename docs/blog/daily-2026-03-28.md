# Validate Your Static Site Pages with curl

A quick way to ensure a page is serving correctly after a deployment is to request it with `curl` and check the HTTP status code and page contents.

## Check the HTTP Status

```bash
curl -o /dev/null -s -w "%{http_code}" https://yoursite.com
```

This command silently fetches the page and prints only the status code, making it ideal for scripts or health checks.

## Check for Content

To verify that an element or content string exists on a page, combine `curl` with `grep`:

```bash
curl -s https://yoursite.com | grep -c "text to match"
```

A return count greater than zero confirms the content is present. This is useful for CI pipelines to ensure deploy integrity.

## Watch for Redirects

To see if a URL is redirecting properly, use the `-L` flag and view headers:

```bash
curl -IL https://yoursite.com/old-page
```

This follows redirects and shows the full chain of Location headers, helping catch redirect loops or broken links early.

These quick checks can be added to Bash scripts or CI/CD pipelines for automated site validation.
